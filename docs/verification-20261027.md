- 로그인한 기존 브라우저 세션으로 업데이트·영업 지도 화면 접근.
- 거래처 47건, 지자체 기록 44건 조회. 거래처 이름 검색 결과 1건 확인 및 지자체 탭 전환 확인.
- 지도 키 미설정 안내가 표시되어 실제 지도 핀·좌표 API 검증은 불가. 환경변수는 변경하지 않음.
- 임의 테스트 품목 1개를 URL로 전달: 제안서에 품목명/학명/규격 반영 및 가격 별도 문의 표시. 견적용 목록에 수량 3 반영. 저장·발행·Airtable 쓰기 없이 확인.

## 변경

- 선택 데이터 공통 검증: UTF-8, 버전, 품목 수/크기 제한, 빈 이름·규격 및 비정상 수량 처리.
- 공식 웹사이트와 오픈가든 소유 웹사이트 Preview의 이미지 API 경로만 허용. 외부 호스트·자격 증명·임의 API 경로 차단.
- 부서/층 정보(예: 별관 A동 3층)를 상세 주소로 잘못 판정하지 않도록 수정.
- 패치노트에서 웹사이트 코드와 ERP 적용 상태를 구분. 외부 웹 기능의 운영 완료를 주장하지 않음.
- 업데이트 알림 모의 검사: 새 버전 감지 후 자동 새로고침 없음, 미저장 폼/저장 중 차단, 정상 완료 후 수동 새로고침, 잘못된 응답 및 로그인 리디렉션 후 재시도.
