# 견적서 작성 기준

- 거래처를 선택하면 쉼표·세미콜론·줄바꿈으로 나열된 성명 중 첫 번째 성명을 문서에 입력한다. 예: `이선미, 민헌기` → `이선미`.
- 공백으로 구분된 이름은 나누지 않는다. 문서의 성명은 직접 수정할 수 있다.
- 성명 변경은 작성 중인 문서에만 적용하며, 등록된 거래처의 성명·담당자 목록은 변경하지 않는다.
- 견적 유효기간은 기본 14일이다. 생성기 **설정 → 문서별 설정 → 유효기간 (일)**에서 14로 설정한다. 설정은 브라우저별이며 이미 발행한 문서는 바뀌지 않는다.
- 고객용 비고에 웹 요청번호를 넣을 필요는 없다. 정식 견적번호로 구분한다.
- 운송비가 상품 금액에 포함되지 않는 견적에는 다음 안내를 사용한다: “운송비는 상품 금액에 포함되지 않으며, 수령 시 운송업체에 별도 정산됩니다.”
- 발행 후 정정은 **견적·주문 → 더 보기 → 수정본 만들기**로 처리한다. 원본을 보존하고 수정본을 발행한다.

## 유지보수

첫 성명 기본 입력은 `public/tools/quote-integration.js`에서 생성기의 공개 핸들러를 연결한다. 거래처 선택, 자동완성 클릭·키보드 선택, 일치하는 거래처 자동 채우기를 지원한다. 기존 발행본이나 초안을 불러오는 동작에는 적용하지 않는다. 생성기 재빌드 시 기존 연동 스크립트 포함을 유지한다.
