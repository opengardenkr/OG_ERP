견적서 전용 설정과 모든 문서에 공통으로 쓰는 설정을 표시합니다.

에어테이블(Airtable) 개인 액세스 토큰(PAT)을 입력하면 거래처·식물 품목을 이 견적서와 양방향으로 동기화합니다. 토큰은 이 기기(브라우저)에만 저장되며 서버로 전송되지 않습니다.

🔑 토큰 만들기: airtable.com → 우상단 프로필 → Developer hub → Personal access tokens → Create token → 스코프 data.records:read, data.records:write, schema.bases:read 선택 → 베이스 OpenGarden 추가.

연동 대상 · 거래처 → 거래처 테이블 · 식물 품목 불러오기 → 국내 라인업 + 판매 라인업 · 식물 품목 저장 → 국내 라인업. 각 탭의 ⬇️/⬆️ 버튼으로 실행하세요.
